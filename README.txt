# Mora y Asociados — Sitio web escolar

## Cómo abrirlo en Visual Studio Code
1. Descomprime esta carpeta.
2. Abre la carpeta `Mora_y_Asociados_Sitio_Web` en Visual Studio Code.
3. Abre `index.html`.
4. Si tienes Live Server instalado: clic derecho en `index.html` > **Open with Live Server**.
5. Si no tienes Live Server, puedes abrir `index.html` directamente en el navegador.

## Estructura
- `index.html` — Inicio
- `nosotros.html` — Quiénes somos
- `servicios.html` — Servicios + tabla
- `galeria.html` — Galería de imágenes
- `contacto.html` — Contacto + formulario + iframe
- `css/styles.css` — Diseño, colores, responsive, bordes, tipografía
- `js/script.js` — Menú móvil, año automático y formulario de demostración
- `images/` — Logo y material visual

## Para personalizar antes de exponer
- Cambia los enlaces de Facebook/Instagram/LinkedIn por los oficiales.
- Si tienes dirección, reemplaza el iframe de contacto por un mapa.
- Puedes sustituir las imágenes repetidas de la galería por fotos propias.
- Si tienes un video de la empresa, reemplaza el bloque multimedia de `index.html`.

## Rubrica cubierta
Mapa de navegación (se incluye aparte), 5 páginas, inicio, encabezado, nombre, quiénes somos, descripción, logotipo, imágenes, contactos, servicios, iframe, anclas, botones/iconos, menús, galería, fondos, redes, listas, tipografía, bordes, multimedia, responsive, alineaciones, tablas y pie de página.
